# Конфигуратор Xpeng G9

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/xpeng-g9-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8940`, затем http://127.0.0.1:8940/

## Что выбирает человек
Версия (Max 625, Max 725, Max 680); цвет кузова, цвет салона, диски; дополнительно – пакет умных функций ultra, пакет умных функций ultra se.
Варианты и их сочетания взяты из официального конфигуратора Xpeng (store.xiaopeng.com): чего производитель не собирает, выбрать нельзя.

## Картинки
Официальные рендеры Xpeng без фона: два вида кузова на сборку (спереди и сбоку) – других ракурсов кузова у производителя нет.
Салон: фото каждой отделки и два вида вперёд (с места водителя и со второго ряда), вырезанные из круговых панорам производителя.
16 сборок кузова, 9 вариантов салона, всё в WebP.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-data.js`, `js/konfigurator.js`, положить рядом папку `img/`. Движок общий для всех моделей Zeekr,
модель задаёт только `js/zeekr-data.js` и картинки. Цвета – токены `--z9-*` в начале CSS (светлая и тёмная тема).

Заявка «Отправить сборку менеджеру»: у формы атрибут `data-endpoint` – адрес приёма заявок сайта,
туда уходит POST JSON `{name, phone, text, url, lines, source, page}`. Пока он пустой, заявка уходит событием:
```js
document.querySelector('[data-z9]').addEventListener('zeekr:lead', e => send(e.detail));
// текущая сборка в любой момент: window.ZeekrCfg.get()  → {text, lines, config, url}
// каждое изменение: событие 'zeekr:change'
```
Ссылку на политику конфиденциальности вписать в `a[data-policy]` формы. Сборка хранится в адресе (`#v=55&o=…`).

## Как обновить данные
1. `python3 tools/xpeng_snyat.py <код серии> .` – пишет `raw/xpeng-raw.json` (код серии – из адреса store.xiaopeng.com/configurate.html?carSeries=…).
   API открытый, браузер не нужен.
2. `tools/xpeng-model.sh g9 "Xpeng G9" "G9"` – картинки, данные, проверки и выкладка (NOPUSH=1 – без выкладки).
   Новое китайское название сборка не пропустит: перевод добавить в RU в tools/xpeng.py.
3. До выкладки просмотреть глазами листы в raw/obzor (каждый кадр салона, кузов по версиям).
4. Проверка выложенной страницы в браузере на сервере: `python3 tools/proverka_vps.py https://tema-mail.github.io/xpeng-g9-konfigurator/`
Движок и стили общие с конфигураторами Zeekr, мастер-копия – репозиторий tema-mail/zeekr-9x-konfigurator.
